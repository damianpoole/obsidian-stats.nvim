# Repository instructions

## Local verification only

Run tests and other verification locally. Do not add, enable, or trigger GitHub
Actions workflows or other hosted CI unless the user explicitly asks for it.
The user wants to conserve their limited GitHub Actions allowance and avoid
paid CI usage. This applies to pull requests as well as changes on main.

Use the local test command documented in README.md. Report the checks performed,
their results, and any platforms or supported versions you could not verify
locally. Do not substitute a hosted CI run for missing local coverage.
